# WellRoundedNews
This is a personal portfolio project which aims to create a well rounded news website that uses an aggregator to tell the news in a non-biased manner. This website also prioritizes design elements and options to limit the cognitive overload of a user. 

## Purpose of Project
Reading the news can feel overwhelming, if you open any given news site you will most likely be bombared with about 5-10 different headlines all at once. This project aims to create a news site that not only limits that cognitive overload but also adds features to make staying informed accessible to all users. This website will focus on design princples that simplify the users experience as well as add features that give users the option to limit the ammount of news they see at once. 
One important feature that I intend to add to this website is the addition of a "What have political actors said about this" section. This section aims to help users understand where certain political actors (such as local politicians, political influencers, etc...) have stood about a particular issue. For those who are in office there will be a button allowing for the user to call or email their political leaders if they are concerned about a specific event. This feature aims to promote active discussions between consitutents and their respective representatives. For political influencers who do not hold office this section will not provide contact information but rather inform users about the stances these influencers have taken on a particular issue. The main purpose is to keep people informed and aware about important figures that lead our political world in a non-biased manner.

## Personal concerns and considerations for this project
- My biggest concern are the legal implications of web scrapping, I must ensure that all information I am scrapping is public as well as making sure that I retrieve sources from all sides.
- Although the idea of non-biased news outlets that use web scraping for its content has already been done before I want to ensure that I am bringing something new and adding unique features to this website.
  - I will accomplish this through adding features that not only prioritize sharing the news in a non-biased manner but also ensure the mental health and clarity of users
  - I will also add features that encourage civil action and wider discussions with leaders and their constituents
  - various prototypes will be built to priortize simplicity and an overall enjoyable user experience.
